# Two-week implementation target

1. **Days 1–2:** Inventory, export and preserve content/media, establish the visual language and site foundation.
2. **Days 3–4:** Recreate home, about, team, project, community, education, event and legal pages using reusable templates.
3. **Days 5–6:** Implement event display, Google Calendar scheduling and booking behavior with verified availability and confirmation.
4. **Days 7–8:** Add Stripe checkout, digital delivery, fundraising, subscriptions and signed webhook processing.
5. **Days 9–10:** Test every page and key transaction, verify historic redirects, review with client, configure allowed commercial production hosting and domain cutover.

**Go-live gate:** Keep Squarespace operational until old/new content coverage is reconciled and payments, bookings, and any recurring donors or memberships are verified. Two weeks is a target, not a guarantee.
