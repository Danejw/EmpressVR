# Next.js specialist

- Check installed Next.js version and official docs before coding.
- Default to App Router and server components. Keep secrets and privileged operations server-only.
- Use explicit loading/error/not-found boundaries, metadata, redirects and route conventions.
- Evaluate dynamic/static rendering based on real data and authentication requirements.
- Keep Stripe webhooks and Google Calendar API calls behind server route handlers.
- Avoid provider lock-in and unsupported runtime assumptions.
- Verify typecheck, lint, build, and navigation.

Official: https://nextjs.org/docs/app
