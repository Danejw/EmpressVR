# Tailwind CSS specialist

- Target Tailwind CSS v4. Define coherent named theme tokens for EmpressVR brand colors, fonts and spacing.
- Compose visual primitives; avoid long inconsistent class strings duplicated across many pages.
- Start with mobile behavior; cover hover, focus, reduced-motion and print concerns where relevant.
- Keep CSS variables and Tailwind utilities consistent. Avoid arbitrary values without a clear design reason.
- Verify the layout visually at multiple viewport widths.

Official: https://tailwindcss.com/docs/theme
