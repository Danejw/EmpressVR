# Frontend design specialist

1. Read `docs/brand.md` and inspect the user's latest visual references.
2. Create a short design direction: primary user goal, content hierarchy, colors, type system, grid, spacing and key states.
3. Propose or implement one coherent pattern vocabulary that remains reusable across content, commerce and scheduling.
4. Keep the experience accessible: landmarks, readable typography, focus, labels, contrast, mobile fit and reduced motion.
5. Include interactive states and success/error feedback, especially for checkout and booking.
6. Review actual browser screenshots. Adjust until brand feel, content hierarchy, spacing and mobile presentation are strong.
7. Avoid generic layouts, gratuitous gradients, random animations and mismatched visual metaphors.
