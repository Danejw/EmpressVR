# Deployment and Vercel specialist

- Verify the current plan's license and quotas before deployment.
- Vercel Hobby is restricted to noncommercial use; EmpressVR's business production site needs permitted commercial hosting.
- Keep build configuration portable; avoid Vercel-only SDKs until clearly justified.
- Isolate server dependencies, environment variables, route handlers and webhooks.
- Use preview environments without live payment secrets. Validate webhook callback URLs and origin configuration.
- Verify deploy logs, performance, error handling and public navigation before declaring a release.
